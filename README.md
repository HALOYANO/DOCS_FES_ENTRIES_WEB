### 「TBSドキュメンタリー映画祭」とは
ドキュメンタリーは、ピュアで社会課題を伝えうる力があり、
比較的自由な表現で真実を追求できるジャンルです。

世相や制約の中で真実を愚直に追い、会社の枠を超えた挑戦の場になることを目指しています。

2026年に6年目を迎え、全国6都市で約15,000人を動員した「TBSドキュメンタリー映画祭」。

2027年映画祭に上映するドキュメンタリー映画企画を募集します。

【応募資格】
